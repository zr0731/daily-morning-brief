#### 壹｜游戏创意

#### 今日出圈观察
最近出圈的一类是小体量“社交推理/狼人杀变体”，代表作《Among Us》《鹅鸭杀》《恐惧饥荒》的轻量模仿品。钩子不在画面，而在“信息不对称+语音/文字互骗”的即时戏剧性，一局 5～10 分钟就能产生可剪辑的名场面。传播靠主播和短视频切片，留存靠朋友开黑和随机匹配的低门槛。付费点通常很轻：皮肤、通行证、房间自定义，不卖数值。关键启示：**规则简单到能一句话解释、每局都能生成“刚才那波”的谈资**，比内容量更重要。

#### 创意 1｜《谁改了参数》
- 卖点：实验室版“谁是内鬼”，玩家在共享代码库里抓偷偷改配置的人。
- 核心循环：每局 6 人进同一张“实验任务表”，多数人按指令跑小游戏攒进度，1～2 名内鬼暗中改参数制造故障；玩家每分钟在做“领任务→执行→看异常日志→开会投票”。
- 范围边界：不做语音系统、不做 3D 场景、不做匹配大厅；只做文字/图标房间码联机，6 人上限，3 张地图。
- 原型可行性：Unity 用 Netcode for GameObjects 做房间同步 + 一套任务小游戏模板，Cursor 可批量生成 UI 和状态机，2～3 周能跑通一局。

#### 创意 2｜《拆解师》
- 卖点：把一台“坏掉的机器”拆成零件，边拆边推断它原本怎么运作。
- 核心循环：每关给一台剖面设备，玩家用螺丝刀/吸盘逐层拆件，每拆一件触发一段“它为什么在这”的推理题；每分钟在“点选零件→读线索→装回去验证”之间循环。
- 范围边界：不做物理模拟、不做自由建造；只做 2D 分层拆解 + 固定关卡，12 关封顶，无剧情分支。
- 原型可行性：本质是“可点击分层图 + 选择题”，Unity UI 加简单动画即可，Cursor 写关卡数据结构和判定逻辑，2 周出 5 关可玩。

#### 创意 3｜《夜班便利店》
- 卖点：一个人守 8 小时夜班，应付醉汉、小偷和奇怪顾客，顺便把账做平。
- 核心循环：每分钟在“补货→收银→应付事件→看监控”之间切换；事件以短对话框和限时选择出现，选错扣钱或惹事，日结时用赚的钱升级货架和防盗。
- 范围边界：不做 3D、不做自由走动；固定柜台视角，2D 纸片人对话，30 种事件、1 张店图，无多人。
- 原型可行性：对话事件表 + 计时器 + 简单经济数值，Unity 的 ScriptableObject 就能搭，Cursor 生成事件文本和条件分支，2～3 周可玩一星期循环。

#### 创意 4｜《回声档案》
- 卖点：你只能听录音破案，每段录音里都藏着被剪掉的那一句。
- 核心循环：玩家拿到一段带时间轴的音频波形，拖动播放、标记可疑片段、对比多段录音找矛盾；每分钟在“听→标→交叉比对→提交结论”循环，提交后给对错反馈。
- 范围边界：不做配音演员、不做自由录音；用 TTS 生成 20 段短音频，5 个案子，线性关卡，无分支结局。
- 原型可行性：Unity 音频波形插件 + 时间轴标记 UI，Cursor 写比对判定规则，2 周能做 2 个案子验证手感。

#### 创意 5｜《影子竞速》
- 卖点： asynchronous 对战——你跑一圈，对手的影子明天来追你。
- 核心循环：玩家在 2D 横版赛道跑酷，每局 60 秒；跑完上传“影子数据”，次日收到好友影子回放并尝试击败；每分钟在“跑→看排名→研究影子路线→再跑”循环。
- 范围边界：不做实时联机、不做赛道编辑器；3 条固定赛道、影子只记录位置/时间戳，排行榜用轻量后端或本地文件模拟。
- 原型可行性：横版移动 + 录制回放是 Unity 入门级任务，Cursor 可生成影子插值和排行榜 UI，2 周出单机+假影子版本。

#### 贰｜概念寓言

#### 寓言

老周在城南开了三十年的锁铺，最拿手的是配钥匙。不是普通钥匙——他专攻那种“万能钥匙”，一条街的锁他都能开，但从不偷东西，帮人开锁取遗物、救急，口碑极好。徒弟小季跟了他五年，学得手快眼准，唯独一件事想不通：师父配钥匙从不看锁，只看人。

“你把这条街每个人走路的样子记下来，比记锁芯有用。”老周说。

小季不信。他偷偷把整条街的锁都拆开研究，画了厚厚一册锁芯图纸，觉得天下没有他开不了的锁。老周看了没说话，只递给他一把新钥匙：“去，开街尾陈婆婆的柜子，她儿子要取房本。”

小季去了。陈婆婆的锁是老式弹子锁，结构简单，他三秒就捅开了。可柜子打开，里面空荡荡。陈婆婆的儿子急了：“房本呢？”小季再试，柜子内壁有暗格，撬开，还是没有。他回去找师父。

老周正坐在门口晒太阳，慢悠悠说：“陈婆婆每天下午三点去买菜，路过你铺子会摸一下门框。她左手无名指少一截，摸门框时总用掌根蹭两下。她儿子十年前离家，走前把房本塞在柜子顶板夹层里——她以为儿子带走了，其实没有。你拆锁不看人，当然找不到。”

小季懵了：“可您从没拆过她家柜子啊？”

“我不用拆。”老周掏出一个小本，上面全是街坊的习惯：“王婶倒垃圾必先看左右，说明她钥匙藏在花盆下；李叔下雨天会多锁一道，说明他柜子里有怕潮的东西。我配的不是锁，是人。你每把锁都开得开，可你不知道该往哪儿看。”

小季还是不服。直到那年冬天，城里来了个开锁比赛。小季一路杀进决赛，对手是个盲人。题目是开一只复杂的保险柜。小季用听针、探针，二十分钟搞定。盲人摸了两分钟柜门，直接拧开——柜子根本没锁，只是把手卡住了。

裁判说：“你听见锁芯转，他听见门轴响。你研究的是‘怎么开’，他研究的是‘为什么以为锁着’。”

小季回去找老周。老周正在修一把锈死的锁，头也不抬：“你拆了一百把锁，可你只拆了‘锁’这个字。我这条街三百户人，每户的锁我都配过，但每把钥匙都不一样——因为每户人怕的东西不一样。你开的是锁，我开的是‘他们为什么装锁’。”

小季这才明白：师父从来不是在配钥匙，他在建一张地图——谁家钥匙放在哪、谁家锁是摆设、谁家柜子后面有暗格。他不需要万能钥匙，他需要知道“哪把锁根本不用开”。

后来小季自己也开了铺子，门口挂块牌子：“本店不配万能钥匙。”有人问为什么，他说：“万能钥匙是骗人的。你开得了所有锁，可你不知道哪扇门后面有你要的东西。真正的本事，是知道哪扇门不用开。”

#### 揭晓：概念名
**搜索成本（Search Cost）——在信息不对称环境中，找到目标所需付出的代价；理性决策的关键不是“能否找到”，而是“值不值得找”。**

#### 隐喻对照
| 故事元素 | 对应含义 |
|---|---|
| 万能钥匙 | 追求“无限能力”的幻觉——开锁技术本身不解决“找什么”的问题 |
| 老周记人走路习惯 | 建立关于“信息分布”的先验知识，降低搜索成本 |
| 小季拆锁画图纸 | 只优化“执行效率”，忽略“搜索方向” |
| 陈婆婆的暗格 | 目标信息存在，但不在“锁”这个维度上——搜索空间错了，再强的能力也白费 |
| 盲人摸门轴 | 用更廉价的信号（门轴响）替代昂贵搜索（拆锁芯），识别“无需搜索”的情形 |
| “本店不配万能钥匙” | 承认搜索成本存在，转而投资于“知道去哪儿找”的元知识 |

#### 为何值得懂
研究生阶段的核心能力不是“解出所有题”，而是在信息过载、目标模糊的开放问题中，判断哪些路径值得探索、哪些信号足以终止搜索。不懂搜索成本的人会陷入“万能钥匙”式的勤奋——样样会开，却开错了门。

#### 叁｜商业故事

#### 故事

2021年春天，成都玉林路的菜市场里，王芳的卤味摊前总是排着队。她的拿手菜是藤椒鸭掌，每天只做两锅，卖完收摊。排队的人里有下班的白领，也有隔壁小区的阿姨。但王芳有个烦恼：卤味保质期短，当天卖不完只能倒掉，一个月下来损耗吃掉近两成利润。

转机来自一个老顾客——在附近写字楼做行政的刘姐。刘姐说：“你干脆做成真空小包，放我们公司零食柜试试，我帮你摆。”王芳半信半疑，买了台三百块的真空机，把鸭掌分装成50克小包，定价9.9元，每包塞一张手写卡片：“藤椒味，冷藏三天内吃完，微波20秒更香。”刘姐在公司茶水间摆了二十包，贴了句“王姐卤味，扫码自取”。

第一周，刘姐微信转来137元，说卖光了，有同事问能不能整箱订。王芳嗅到机会，但她没急着扩产，而是先做了三件事：第一，把每周三定为“卤味日”，只在这天集中卤制、真空、配送，把生产从“每天不确定”变成“一周一次确定性批量”；第二，拉了个“玉林卤味拼单群”，群里接龙预订，满30包就开一锅，先收钱后做货；第三，给刘姐这样的“点位主”每包返利1元，刘姐一个月能赚两百多块零花钱，主动帮她推。

到2022年底，王芳没开分店，但通过17个“业余点位主”——前台、便利店老板、宝妈群主——覆盖了周围三公里四十多家公司和小区。她的成本结构很轻：自家厨房生产，真空机加冰袋保温箱总共不到两千块，配送靠点位主自取或拼单满额时她骑电动车送。最绝的是，她把损耗率从18%压到3%以下，因为接龙预订基本做到“以销定产”。

2023年，有家本地食品厂找她谈代工，说可以帮她做长保版进商超。王芳拒绝了，理由是：“我的鸭掌卖的就是‘这周现卤’的新鲜感，进了商超跟货架上的工业卤味拼价格，我拼不过。”她继续守着“小批量、多点位、先收钱”的模式，2024年月利润稳定在2.6万左右，比她当年在菜市场翻了三倍，还不用天天出摊。

#### 商品 / 服务
社区卤味“预订制+点位代销”小生意：藤椒鸭掌按周批量卤制，通过业余点位主在办公室和小区内分销。

#### 商业模式拆解
- **客户**：三公里内的上班族和小区居民，嘴馋但没时间逛菜市场、对“当天现卤”有信任感的零食消费者。
- **价值**：用“周更现卤+真空小包+点位就近自取”解决两个痛点——顾客想吃新鲜卤味但不愿专程跑腿；点位主零成本赚零花、顺带给自己工位或店面引流。
- **收入**：9.9元/50克小包零售，满30包开锅的接龙预订先收钱；点位主每包返1元，相当于用10%渠道分成换免费铺货和熟人信任。
- **成本或护城河**：核心成本是原料和自家厨房人工，护城河是“以销定产+熟人点位网络”——预订制压死损耗，点位主的关系链让大厂很难复制这种邻里信任。
- **个人启发**：做副业别急着扩产能，先找一个“能先收钱再干活”的预售场景，把固定成本压到最低；再设计一个让帮你卖的人赚小钱的分润机制，你就能用别人的时间和信任撬动自己的供给。
