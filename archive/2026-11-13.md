#### 壹｜游戏创意

#### 今日出圈观察
最近出圈的是“轻量 Roguelike + 自动战斗/自走棋”品类（如《背包乱斗》《幸运房东》）。钩子是“组 Build 的决策密度高、单局 10～20 分钟”，传播点是截图分享离谱组合与种子码。留存靠局外解锁新道具/角色，付费点是买断或皮肤，不做数值付费。关键一项：**单局短 + 组合爆炸**，让玩家愿意反复重开。

#### 创意 1｜《叠层药水》
- 卖点：把材料按顺序叠进瓶子，顺序错了就炸，对了就做出连锁反应药水。
- 核心循环：每 30 秒选 3 个材料 → 拖拽排序 → 看物理模拟连锁 → 结算金币买新瓶子和材料 → 下一单。
- 范围边界：不做剧情、不做多人、不做 3D；只做 2D 刚体 + 20 种材料 + 5 种瓶子。
- 原型可行性：Unity 2D 物理 + Cursor 生成拖拽排序和结算逻辑，2 周能跑通一局。

#### 创意 2｜《夜班便利店》
- 卖点：一个人守便利店夜班，边补货边应付奇怪顾客，天亮前别破产。
- 核心循环：每分钟处理 3～5 个顾客订单 → 去货架补货 → 收银找零 → 应对小偷/醉汉 → 日结算升级货架和监控。
- 范围边界：不做开放世界、不做联机；只做一间 20×20 的店、30 种商品、10 种顾客事件。
- 原型可行性：状态机 + UI 交互为主，Cursor 能快速生成事件表和对话，3 周出可玩循环。

#### 创意 3｜《回声地牢》
- 卖点：你发出的声音会变成敌人的行动路线，安静走还是大声清场自己选。
- 核心循环：每步选择“走/喊/扔石头” → 声波扩散吸引或推开敌人 → 利用回声撞墙击杀 → 拾取噪音道具 → 下一层。
- 范围边界：不做复杂剧情、不做联机；只做 1 种敌人 AI + 8 种噪音道具 + 5 层随机地牢。
- 原型可行性：网格回合制 + 声波扩散算法，Cursor 写寻路和扩散逻辑，2～3 周可验证。

#### 创意 4｜《遗物快递员》
- 卖点：你送的不是快递，是会说话的遗物，每单都要决定拆不拆。
- 核心循环：接单 → 看遗物独白 → 选择拆开/不拆 → 影响收件人结局 → 结算信誉和线索 → 解锁新地址。
- 范围边界：不做配音、不做分支动画；只做文本 + 静态立绘 + 20 个遗物 + 3 条结局线。
- 原型可行性：对话树 + 简单状态记录，Cursor 生成剧本模板和分支 UI，2 周出短篇原型。

#### 创意 5｜《影子竞速》
- 卖点：你跑过的路线会变成别人的障碍，异步对抗不等人。
- 核心循环：跑 60 秒赛道 → 系统记录你的轨迹为“影子” → 下次跑时躲别人的影子 → 排名拿零件改装 → 再跑。
- 范围边界：不做实时联机、不做车辆物理；只做 1 条赛道 + 10 种障碍 + 异步影子回放。
- 原型可行性：轨迹录制/回放是 Unity 基础功能，Cursor 写排行榜和影子数据格式，2～3 周可玩。

#### 贰｜概念寓言

#### 寓言

老周在城郊开了二十年的渡口，两岸之间隔着一条不宽不窄的河。他有一条铁皮渡船，船底补过七次，发动机换过三回，但老周说这船还能再撑十年——他算过，每年修船的钱不到换新船的四分之一。

镇上的人都知道老周的规矩：过河不收钱，但每人得在木匣里投一张票，票上写着自己的名字。月末老周按票分红，投得多的人分得多。这套办法是三十年前老周的师父定下的，师父说，河是大家的，船也是大家的，谁出力谁得利。

后来镇上搬来一个年轻人，姓陈，在县里念过几年书，回来搞什么“乡村振兴”。小陈第一次坐老周的船就皱了眉头，下船后掏出一沓纸找老周，说：“周叔，您这票制有问题。您看，王婶天天过河卖菜，投了三十张票；李老师一周才过两回，投了八张。可王婶分到的钱只比李老师多四成，这不对。”

老周抽着烟没吭声。小陈接着说：“我帮您设计个新法子。每人过河投一张票，但票价按人头算——过河次数多的人，每张票的‘权重’递减。您这叫边际贡献递减，我论文里写过的。”

老周把烟屁股摁灭在船舷上：“你论文里写没写过，王婶的菜烂在码头上怎么办？”

小陈没听懂。他还是热心地画了一张表，说按新法子，每人投的票数乘以一个系数，系数随次数增加而变小，最后大家分到的钱更“公平”。老周被缠了三天，终于答应试试。

第一个月，王婶还是天天过河，但她发现投到第十张票之后，每多投一张，月底多分的那点钱还不够买一碗面。她想了想，把最后几筐菜挑回了家。李老师倒还是投八张，但他在学校跟同事说：“老周的船要黄了，你们赶紧存点票，以后说不定能升值。”结果全镇的人都开始囤票，过河的人越来越少。

第二个月，老周修船的钱凑不齐了。他把小陈叫来，指着船底新漏的水说：“你那表画得挺好看。可王婶不来了，李老师囤票，船没人坐，票不值钱，我拿什么修船？你算的是每人该分多少，我算的是这船还能不能开。”

小陈涨红了脸：“可您的旧法子确实不公平啊，王婶贡献大，分得少……”

老周把木匣倒扣过来，哗啦啦一堆票洒在船板上。“你捡起来数数，王婶的票是不是最多？她投得多，分得多，虽然比例上不显眼，但她愿意接着投。李老师囤票，票烂在他手里，下个月他就得乖乖来坐船。你这新法子一上来，王婶先不投了，船坏了，李老师的票也成废纸了。”

小陈蹲在船板上捡票，捡着捡着不动了。他忽然想起自己论文里那个图表——横轴是过河次数，纵轴是每张票的边际收益，曲线向下弯。老师当时说，这条线画出来好看，但你别忘了问一句：河对岸的人，还愿不愿意上船。

老周把船篙往水里一插：“你那个法子，单看每个人是公平的。可你把王婶的劲头给算没了，她把菜挑回家，河这边就少了一个天天想过河的人。李老师囤票，是因为他觉得票会涨——可他囤的票不坐船，船就漏。你算的是分饼，我算的是做饼的人还在不在。”

小陈后来把那张表贴在了村委会墙上，底下加了一行手写的字：“本表假设所有人对票的估值不变，且不考虑票的流动性对船体维护的影响。”没人看懂，但老周路过时点了点头。

船又开了三年。王婶还是天天投票，李老师偶尔囤几张，但每个月总得坐两回过河去学校。老周修船的钱没断过，虽然每次修完他都骂一句：“这破船，再撑十年。”

#### 揭晓：概念名
**机制设计中的激励相容约束**——一个机制要有效，必须让每个参与者在追求自身利益时，恰好也做出机制设计者希望他们做的事；如果参与者发现“说实话/按规矩做”不如“钻空子/退出”划算，机制就会崩溃。

#### 隐喻对照
| 故事元素 | 对应含义 |
|---|---|
| 老周的票制（投多少票分多少红） | 原始机制：参与者的回报与其贡献正相关，保证“出力的人愿意继续出力” |
| 小陈的“边际贡献递减”新规 | 一个看似更公平、但忽略激励相容的机制设计（二级价格歧视/非线性定价的粗糙类比） |
| 王婶减少投票、把菜挑回家 | 激励不相容：高贡献者发现边际回报太低，选择退出/降低努力 |
| 李老师囤票、同事跟风 | 策略性行为：参与者发现规则的漏洞后，从事非生产性套利，进一步抽干系统 |
| 船底漏水、修船钱凑不齐 | 机制崩溃：系统的维护资金（公共品供给）依赖于参与者持续的真实参与，一旦参与萎缩，系统无法自我维持 |
| 老周说“你算的是分饼，我算的是做饼的人还在不在” | 机制设计的核心追问：不仅要问“分配是否公平”，更要问“参与约束和激励相容是否满足” |
| 小陈最后加的那行手写备注 | 研究生论文里常见的“假设条件”被现实打脸——模型没写清楚的前提，恰恰是系统存活的关键 |

#### 为何值得懂
研究生阶段设计的模型、政策、合约或算法，往往默认“参与者会按我设想的激励行动”。但真实世界里的人会退出、会囤积、会钻空子——**激励相容约束**提醒你：一个机制好不好，不看它在纸面上多精巧，而看每个参与者在自己的立场上，有没有理由继续留在局里、继续做你希望他做的事。

#### 叁｜商业故事

#### 故事

2023年春天，成都玉林菜市场的卤味摊主刘姐发现，隔壁新开的“鸭哥卤味”门口总排着队。她悄悄观察了一周：对方下午四点出摊，六点半就卖光收工，客单价还比她高30%。刘姐忍不住去买了一只鸭脖——味道确实不错，但真正让她愣住的是付款时的一幕：店员递来一张手写卡片，上面印着“鸭哥卤味·玉林3群”，附一个二维码，写着“进群每天抽5斤鸭脖，还教你怎么热卤味最好吃”。

刘姐回家扫码进了群。群里有三百多人，每天下午两点，老板“鸭哥”会发一条语音，嗓门洪亮：“今天卤了80斤，四点出摊，老规矩，群里提前接龙可以留货，卖完就收。”接龙小程序里，群友纷纷留言“鸭脖2斤、鸭翅1斤”。鸭哥还隔三差五发短视频：凌晨四点去白家批发市场挑鸭货、大锅熬卤水的咕嘟声、切鸭脖的脆响。评论区有人问“能不能真空寄外地”，鸭哥回复：“先做透三公里，不贪。”

刘姐算了笔账：鸭哥每天只卤80斤左右，按均价25元/斤算，日流水约2000元，月流水6万。摊位租金便宜，只有她的一半——因为鸭哥专挑菜市场外围的“边角位”，租金低但离小区出口近。更关键的是，群里接龙让他的损耗几乎为零：每天按接龙量加20%备货，基本不剩。而刘姐自己每天卤50斤，经常剩10斤，损耗吃掉近两成利润。

转折发生在2024年夏天。鸭哥在群里宣布：“玉林3群满500人了，开4群。另外，从下个月起，每周三做‘川味卤菜课’，99元/人，教你在家卤一锅不翻车的鸭货，送一包我的老卤引子。”刘姐心想：卖卤味还卖课？有人买吗？结果第一期20个名额，半小时抢光。来上课的多是年轻妈妈和下班后想搞副业的上班族。课上鸭哥不藏私，连香料配比都写在黑板上，最后一句是：“你们学会了在家做，想吃随时做；但要是想摆摊，记得来找我拿稳定货源——我帮你对接批发商，每斤抽五毛。”

到2025年底，鸭哥有了6个微信群、近3000个附近居民，每周三的卤菜课稳定开两期，还上线了“鸭哥卤味·家庭装”真空包，同城闪送。有人问他为什么不搞直播卖全国，他摆摆手：“全国包邮的鸭脖满大街都是，我比不过工厂。但三公里内‘今天卤今天吃’的新鲜，加上群里喊一嗓子就留货的方便，工厂抢不走。”

刘姐后来也学了一招：把自己的老顾客拉了个群，每天发“今日卤味出锅视频”，接龙留货。损耗降了一半。她没卖课，但开始在群里搭着卖自家做的泡椒凤爪——鸭哥不卖这个，不冲突。

#### 商品 / 服务
社区卤味摊的“微信群接龙+小课引流”模式，靠三公里内新鲜现卤和零损耗运营赚钱。

#### 商业模式拆解
- **客户**：摊位周边三公里的小区居民（高频复购的日常佐餐），以及想学卤味手艺的年轻妈妈/副业新手（低频高客单的课程）。
- **价值**：对食客，解决“想吃新鲜卤味但不想排队/怕卖完”的痛点，接龙留货+出锅视频给确定性；对学员，解决“网上配方不靠谱、不敢下手”的痛点，用真摊主现场教+送老卤引子降低启动门槛。
- **收入**：主力是卤味零售（约25元/斤，日流水2000元上下，月约6万）；增量是卤菜课（99元/人，每周两期约40人，月增收近8000元）；后续还有真空包同城闪送和给学员对接货源的每斤五毛抽成。
- **成本或护城河**：按接龙备货把损耗压到近零，加上“边角位低租金+三公里新鲜现卤”的组合，工厂标准化产品抢不走“今天卤今天吃”的社区信任。
- **个人启发**：做副业先别想着卖全国，把身边三公里内一群人的一个高频小痛点吃透——用微信群接龙锁定需求、按需备货降损耗，再用“教别人做”把信任变现成第二收入，比盲目扩品类更稳。
