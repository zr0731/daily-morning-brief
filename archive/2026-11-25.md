#### 壹｜游戏创意

#### 今日出圈观察
最近《Balatro》式小丑牌品类持续出圈，核心是“把扑克牌型换成乘法连招”——每局 10～15 分钟，抽牌、组 combo、看分数爆炸，传播点是一张截图就能让人问“这分数怎么打出来的”。另一类是《Buckshot Roulette》式短平快惊悚互动，靠主播反应和“下一枪会不会响”的简单悬念驱动，付费点轻、传播靠切片。共同点：规则一句话说清、单局短、有随机性制造的故事性、不需要 3A 美术也能卖。

#### 创意 1｜骰子工坊
- 卖点：每回合往自己骰子上贴词条，让一颗 d6 滚出“暴击+吸血+连锁”的荒诞组合。
- 核心循环：每回合从 3 个随机词条中选 1 个贴到骰面 → 掷骰对怪物造成伤害 → 掉落的金币用于扩骰面或买新骰子 → 第 8 回合打精英，看 build 是否成立。每分钟约 2～3 次决策。
- 范围边界：不做剧情、不做多角色养成、不做装备系统；只有 1 种敌人模板加 3 个精英变体，数值全用 ScriptableObject 配。
- 原型可行性：词条效果就是“伤害+2”“30% 触发连击”这类简单 if 判断，Cursor 补全枚举和 switch 很快，2 周能跑通一局 10 分钟循环。

#### 创意 2｜快递分拣员模拟器
- 卖点：在传送带速度越来越快时，把包裹按颜色/地址扔进正确滑槽，偶尔混进一个“炸弹件”要手忙脚乱地丢进隔离箱。
- 核心循环：包裹从左滚来 → 玩家拖拽或按键分到 4 个滑槽 → 正确得分、错误扣时间 → 每 60 秒提速并解锁新规则（如易碎件要轻放）。每分钟处理 20～30 件。
- 范围边界：不做 3D、不做物流经营、不做剧情；只做 2D 俯视传送带和 UI 分数，音效靠免费素材。
- 原型可行性：核心就是“物体移动 + 碰撞判定 + 计分”，Unity 2D 基础教程水平，Cursor 写个 object pool 和事件系统，1～2 周出可玩 demo。

#### 创意 3｜回声档案
- 卖点：用“倒放录音”破案——每段证词只能听倒放版，玩家在脑内（或纸笔）还原正放内容，找出矛盾。
- 核心循环：进入一个场景 → 拿到 2～3 段倒放音频 → 拖动进度条反复听、标记关键词 → 从嫌疑人列表选一个指认 → 对错影响下一场景的线索数量。每分钟在听、记、选之间切换。
- 范围边界：不做配音演员、不做分支结局树；只做 5 个案件、每案 3 段音频，文本用本地 JSON，音频用免费 TTS 倒放。
- 原型可行性：倒放就是 AudioSource.pitch = -1 或预处理音频，UI 只需进度条和选择按钮，Cursor 写个简单的线索状态机即可，2～3 周。

#### 创意 4｜异步斗蛐蛐
- 卖点：自己配一套“蛐蛐技能组”上传，下线后别人来打你的 AI 蛐蛐，看战报回放谁赢。
- 核心循环：给蛐蛐选 3 个技能（冲撞/闪避/毒咬）→ 点“出征”自动匹配一个离线玩家的蛐蛐 → 看 30 秒自动战斗回放 → 赢了拿积分换新技能。每分钟主要是配装和看战报，不要求实时在线。
- 范围边界：不做实时 PvP、不做排行榜服务器；用本地存档模拟“其他玩家”（预置 20 个 AI 蛐蛐），异步用 JSON 存技能组。
- 原型可行性：战斗就是回合制自动结算，Cursor 写个状态机和战报文本生成器，1～2 周能出单机版“假异步”原型，验证手感后再接后端。

#### 创意 5｜深夜便利店
- 卖点：值夜班时应付醉汉、小偷和“只想聊天的怪客”，每个顾客 30 秒内决定是结账、赶走还是听他说完。
- 核心循环：顾客走到柜台 → 弹出 2～3 个选项（扫码/报警/递烟）→ 选错扣心情值，选对加钱或解锁小故事 → 心情归零则当晚结束。每分钟接待 1～2 人，节奏慢但选择有压力。
- 范围边界：不做 3D 场景、不做自由移动；只用静态背景图 + 立绘 + 对话框，顾客 15 个、每人 3 句台词封顶。
- 原型可行性：本质是带计时器的对话选择器，Cursor 写个对话树和心情变量，1 周能出可玩 vertical slice，适合先验证“选择是否有趣”。

#### 贰｜概念寓言

#### 寓言

清水镇上有两个面包师，一个叫阿禾，一个叫阿满。两人师出同门，手艺不相上下，连烤炉都是同一批砖砌的。镇上的人起初分不出谁家的面包更好，直到有一年，镇外那条河改了道。

河改道本是件小事，可它把镇子通往磨坊的路冲断了。阿禾起早贪黑，绕远路去邻镇买面粉，回来时天都黑了，烤出的面包一天比一天硬。阿满却蹲在断路口看了一整天，第二天开始收镇上人家囤的陈麦，又跑去和河对岸的渔夫谈，用面包换鱼，再把鱼卖给不靠河的肉铺。三个月后，阿禾还在绕远路，阿满面包房里已经多了一台用废铁改的小磨，能磨陈麦，也能磨渔夫晒的干薯。

镇里人觉得阿满运气好，碰上了渔夫。阿禾不服，说：“我若也去和渔夫谈，一样能成。”他真去了，谈得也不错，可等他谈成回来，阿满已经和渔夫、肉铺、磨坊三头都签了契约，谁想插进来，都得先问阿满缺什么。阿禾这才发现，自己每走一步，都要看阿满先走的那一步落在哪里。

又过一年，镇上闹旱，麦价飞涨。阿禾咬牙囤了一批麦，等着涨价。阿满却把磨坊开放给所有面包师，只收一点加工费，条件是磨出的麸皮归他。旱季一过，阿禾的麦子霉了一半，阿满攒了一仓麸皮，拿去喂了镇上没人要的瘦猪，年底卖猪的钱比卖面包还多。阿禾气得砸了一个烤盘，说：“你就是会钻空子。”

阿满没生气，只递给他一块新烤的面包，说：“师兄，你每一步都想着怎么把面包烤得更好。我每一步都想着，等这步走完，镇上还有哪些路是别人绕不开我的。”

阿禾嚼着面包，忽然觉得嘴里发苦。他想起小时候师父教他们揉面，师父说：好面包师要盯着手里的面团。可师父没说过，当河道改了、磨坊断了、麦子贵了，盯着面团的人，最后连面团都保不住。

那天晚上，阿禾第一次没有去揉面。他坐在断路口，看着河对岸渔夫家的灯，一条一条数着镇上还有哪几户人家，明天一早必须从谁家门前过。

#### 揭晓：概念名

**路径依赖与锁定效应**：一个系统（或个人、组织）早先的选择会通过正反馈不断强化自身，使后来者即使面对更优选项，也难以退出既有轨道；转换成本越高，系统越被“锁定”在次优路径上。

#### 隐喻对照

| 故事元素 | 对应含义 |
|---|---|
| 河改道、断路 | 外部冲击改变环境参数，原最优路径失效 |
| 阿禾绕远路买面粉 | 沿既有路径追加投入，沉没成本驱动继续沿旧路走 |
| 阿满先与渔夫、肉铺、磨坊签契约 | 早期选择形成正反馈：每多一个节点，网络价值上升，后来者更难插入 |
| 阿禾“谈得也不错，但阿满已三头都签” | 先发优势转化为转换成本，后来者被排除在既有路径之外 |
| 阿满开放磨坊、收麸皮 | 路径一旦建立，系统会围绕它生成新的互补资产，进一步加固 |
| 阿禾囤麦等涨价、霉掉一半 | 在旧路径上做局部优化，忽略路径本身已不匹配环境 |
| 阿禾数“明天必须从谁家门前过” | 意识到锁定效应的存在：不是面团不好，是路被占了 |

#### 为何值得懂

研究生做研究、选方向、建方法时，最贵的往往不是“选错”，而是选错之后被沉没成本、合作网络和互补资产锁在原地，看不见环境已经变了。理解路径依赖，才能分辨自己是在优化面包，还是在优化一条已经绕不开别人的路。

#### 叁｜商业故事

#### 故事

2021年春天，成都玉林路一家独立咖啡馆里，店主林薇正对着三张纸发愁：一张是房东涨租30%的通知，一张是外卖平台抽成22%的合同，第三张是她手写的月度流水——堂食客单价38元，但每天只有约40单，扣掉原料和人工，月底剩不下几千块。隔壁新开的连锁品牌用9.9元美式抢走了不少熟客，林薇算过，自己跟不起这个价。

转机来自一个雨天。一位老客抱怨：“你们家豆子比连锁店好太多，但我总不能天天专门跑一趟，外卖送来又洒又凉。”林薇突然意识到：她的核心资产不是那间租金昂贵的店，而是烘焙师老陈每周手冲的六款单品豆，以及三百多个熟客的微信。

她做了三件事。第一，把店里最受欢迎的“周三拼配”做成挂耳包，5片装定价39元，成本约12元（豆子+滤袋+包装+人工分装）。第二，在熟客群里发起“月度咖啡订阅”：每月99元，每周配送一盒5片装挂耳，附一张老陈手写的风味卡，成都三环内次日达。第三，把咖啡馆二楼改成小型烘焙间和打包区，堂食只保留靠窗六桌，其余面积不再为“翻台率”服务，而是为“复购率”服务。

头一个月，订阅只卖出23份。林薇没投广告，而是让每位订阅用户拉一位朋友首月半价（49元），朋友续订后，推荐人得下一月减20元。到2022年夏天，订阅用户稳定在410人，月流水约4万元，毛利率约55%。更关键的是，挂耳包不受堂食时段限制——早上七点上班族出门前顺手拿一盒，比等外卖快；老陈的风味卡被用户拍照发小红书，带来了几十个自然搜索订单。

2023年，林薇关掉了临街一楼，只留二楼烘焙间和自提窗口，月租从1.8万降到6千。她把省下的钱投进两件事：一是给老陈涨薪并送他去考Q Grader（咖啡品质鉴定师），二是开发“企业下午茶”B端订单——附近三家设计公司每月各订30盒，单价35元，走对公转账，没有平台抽成。现在她一个人管订阅客服和排产，老陈带一个兼职分装，月净利润约2.2万，比堂食时代翻了一倍，且不再看房东和平台脸色。

#### 商品 / 服务

精品挂耳咖啡的月度订阅制（DTC复购模式），辅以企业团购。

#### 商业模式拆解

- **客户**：成都三环内25–40岁、有日常咖啡习惯但没时间到店的上班族（C端订阅）；以及附近中小设计/广告公司行政人员（B端团购）。
- **价值**：用“比连锁店好喝、比外卖新鲜、比到店省时”的挂耳包，把精品咖啡从“到店体验”变成“家庭/办公室耗材”；风味卡和手写感提供情绪价值，降低选择成本。
- **收入**：C端订阅99元/月（首月拉新半价49元），B端35元/盒起订30盒；渠道以微信私域群+老客转介绍为主，不依赖外卖平台抽成。
- **成本或护城河**：核心成本是豆子与分装人工，护城河是“烘焙师手艺+熟客信任关系+订阅制带来的可预测现金流”，而非门店位置。
- **个人启发**：副业起步时，别急着为“流量”付租金或抽成，先盘点自己手里已有的“信任资产”（熟客、手艺、社群），把它产品化成可重复交付的小规格商品，用订阅制把一次性交易变成月度现金流——哪怕只有几十个铁杆用户，也比在平台上跟低价卷堂食更稳。
