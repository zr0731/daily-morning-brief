#### 壹｜游戏创意

#### 今日出圈观察
近期《Balatro》和《小丑牌》类 Roguelike 卡牌持续出圈，核心不是“卡牌”本身，而是**每局 20 分钟内能叠出指数级爽感**：小丑牌乘算联动、种子分享、每日挑战，让玩家自发在社交平台晒“这局胡了”。传播点是**截图即内容**——一张离谱的倍率面板就是最好的广告。付费逻辑极轻：一次性买断 + 移动端低价，靠“再开一局”的留存而非内购。另一条线是《Chained Together》《Only Up!》这类**短时长、高失败、强表演性**的联机/直播向小游戏，靠主播反应出圈，但个人开发者难吃联机运维。结论：单人、短局、可截图、低运维，是研究生副业最稳的出圈结构。

#### 创意 1｜《叠叠乐工坊》
- 卖点：把“合成大西瓜”的物理堆叠和 Roguelike 的每局词条结合，堆出屏幕外的一摞就是你的成绩单。
- 核心循环：每分钟玩家在窄口容器里投放形状各异的零件，同色相邻自动焊接加分；每 60 秒三选一词条（如“焊接爆炸”“重力反转”），堆到顶则本局结束，结算截图分享。
- 范围边界：不做联机、不做关卡编辑、不做 3D 物理，只做 2D 刚体 + 固定容器 + 20 个词条。
- 原型可行性：Unity 2D 物理 + 简单 UI 三选一，Cursor 可代写碰撞合并与词条系统，2 周内能出可玩循环。

#### 创意 2｜《回声地牢》
- 卖点：你听不见声音，但地牢会“回声”——每次攻击/移动发出声波，声波撞墙反弹后显示敌人位置，玩的是“盲打”。
- 核心循环：每分钟玩家在纯黑网格中移动，按键发出脉冲，回声波纹短暂勾勒出墙壁与敌人轮廓；玩家靠记忆和波纹时机决定下一步，清层后获得新脉冲类型（扇形、穿透、延迟）。
- 范围边界：不做实时战斗动画、不做剧情、不做多角色，只做网格移动 + 波纹渲染 + 5 种敌人 AI。
- 原型可行性：核心是 shader 波纹和网格逻辑，Cursor 能快速生成回声扩散与敌人巡逻代码，3 周可玩。

#### 创意 3｜《深夜便利店进货员》
- 卖点：你不是店长，是那个凌晨三点对着进货单算保质期的打工人——模拟经营的最小切口。
- 核心循环：每分钟玩家看当日客流预测和货架剩余，从 8 种商品里下单、定价、摆位；打烊后结算损耗与利润，连续 7 天不破产则解锁新店型。核心张力是“订多了烂掉，订少了少赚”。
- 范围边界：不做 3D 店面、不做员工管理、不做剧情分支，只做数值面板 + 每日结算 + 30 个随机事件。
- 原型可行性：纯 UI + 数值表，Cursor 写结算公式和事件池极快，2 周能出“再开一天”的循环。

#### 创意 4｜《她留下的语音条》
- 卖点：你继承了一部旧手机，里面只有 12 条未读语音，每条听完才能解锁下一条——叙事靠“听”而非“读”。
- 核心循环：每分钟玩家在手机界面里点开语音、拖动进度条、在便签里记关键词；语音内容随播放顺序不同产生歧义，玩家最终要拼出一个“她为什么离开”的答案并提交，系统按关键词匹配给出 3 种结局。
- 范围边界：不做配音演员、不做分支树爆炸，只做 12 条文本转语音 + 关键词判定 + 手机 UI 皮肤。
- 原型可行性：Unity UI + 系统 TTS + 简单字符串匹配，Cursor 可代写播放器与判定逻辑，2～3 周出完整体验。

#### 创意 5｜《幽灵快递》
- 卖点：异步对抗——你给对手留包裹，对手上线后拆包，拆错就炸；玩的是“隔空互坑”。
- 核心循环：每分钟玩家从 3 个包裹里选一个寄给随机对手（可塞陷阱或真货），同时拆自己收到的 3 个包裹；拆包有倒计时和剪刀次数限制，猜错扣分。无实时联机，靠服务器排队异步匹配。
- 范围边界：不做实时 PvP、不做聊天、不做账号体系，只做匿名 ID + 包裹队列 + 简单排行榜。
- 原型可行性：Firebase 或 PlayFab 免费 tier 存队列，Cursor 写云函数与拆包状态机，3 周可跑通异步循环。

#### 贰｜概念寓言

#### 寓言

清河县今年换了新县令，姓周，三十出头，进士出身，最信“规矩”二字。到任头一件事，就是把全县的粮仓重新编册：东仓、西仓、南仓、北仓，四本大账，每月初五各仓头目来县衙对一次数，少一斗都要问罪。

管东仓的老吏姓孙，在仓里干了二十三年，闭着眼都知道哪面墙受潮、哪扇窗漏风。头一个月对账，东仓账上少了三石。孙老吏说是耗损——老鼠嗑的、麻袋缝里漏的、量斗时刮下来的底儿，历年来都这样。周县令把桌子一拍：“什么叫历来都这样？少三石就是少三石，补上。”孙老吏只好拿自己的俸禄填了。

第二个月又少了三石。孙老吏不填了，跪在堂前说：“大人，这三石不是丢了，是量不出来。您若不信，亲自去仓里看着装一斗。”

周县令真去了。他站在东仓门口，看小吏拿斗往袋里舀米，一斗、两斗、三斗，数到第一百斗，封袋、过秤。然后他把那袋米倒回仓里再舀一遍，又是第一百斗，再封袋、过秤。两袋米往秤上一放，差了两斤半。

周县令愣了。同样的米、同样的斗、同一个人舀，两遍竟不一样。

孙老吏在旁说：“大人，米是活的。天潮它就沉，天干它就轻；装得急就实，装得慢就松；您站得近，小吏舀得快，您站得远，他就舀得匀。您要的是‘准’，可这仓里的米从来只给一个范围，不给一个死数。”

周县令不信邪，调了西仓的头目来舀东仓的米，又调南仓的头目来称，折腾三天，最后得出个让他睡不着的结论：同一仓米，同一天称，不同的斗、不同的人、不同的时辰，报上来的数能差出五斗去。而这五斗，正好卡在“贪了”和“没贪”之间。

他若把标准定死在账上那个精确数，全县四个仓头目个个都得填俸禄，明年就得辞官不干；他若不管，又怕真有人往里伸手。

周县令在书房坐了一夜。天亮时他做了个怪决定：不再追那个精确数，改为“两本账”——一本记实数，由各仓头目自己报，报多少算多少，但每月随机抽一天，他亲自带人突袭过秤，突袭的数与自报的数只要不差过六斗，就算过关；差过了，才问罪。另外他加了一条：四个仓头目每季度轮换管仓，你管东仓我管西仓，谁也别想在一个仓里养出自己的人才。

孙老吏听说后，回家跟儿子说：“这新县令，头一个月像要杀人，第三个月倒像懂行了。”

儿子问：“他不怕人家合伙糊弄他？”

孙老吏说：“你还没看明白？他压根没打算量准。他要的是——**谁也别想在一个地方待久了，把误差养成自己的私房**。他那个‘六斗’不是标准，是个口袋。口袋扎紧了，米还是那些米；口袋松一点，反倒没人敢往里头多抓。”

后来县里果然太平。不是账目变准了，是四个仓头目互相盯着，谁也不敢在自己管的那三个月里多舀一勺——因为下季度换别人来管，突袭一称，差得多了，上家跑不掉。

年底周县令给府里写报告，师爷问他怎么写。他提笔写了八个字：“数不可尽信，制可制其奸。”师爷看不懂，周县令说：“你就照抄，府台大人看得懂。”

#### 揭晓：概念名

**委托—代理问题中的“信息不对称”与“激励相容”**——（更精确地说，是机制设计里的**“不完全监督下的激励相容约束”**：当委托人无法低成本观测代理人的真实努力/真实信息时，最优合同不是追求精确计量，而是设计一套让代理人“说真话、不偷懒”比“说谎、偷懒”更划算的规则。）

#### 隐喻对照

| 故事元素 | 对应含义 |
|---|---|
| 周县令 | 委托人（principal） |
| 孙老吏等仓头目 | 代理人（agent），掌握本地私有信息 |
| 粮仓的米“量不准” | 产出/信息不可无成本精确观测，存在测量误差与噪声 |
| 头两个月“少三石就补” | 强监督/精确问责合同：在噪声大的环境下不可行，会逼走代理人或逼其造假 |
| 突袭过秤 + 六斗容差 | 随机审计 + 容忍区间：承认噪声，降低监督成本，同时保留威慑 |
| “六斗”不是标准是口袋 | 激励相容约束：规则的目的不是测准，而是让代理人自己选择不违约 |
| 四仓头目季度轮换 | 减少代理人长期盘踞的信息租金，打破合谋与“养误差” |
| “数不可尽信，制可制其奸” | 机制设计核心：当信息不可完全获取时，靠制度（而非更细的账）约束行为 |

#### 为何值得懂

研究生阶段大量问题——从导师—学生、股东—经理、平台—骑手到政府—企业——本质都是“你只能看到结果，看不到对方知道什么、干了什么”。不懂信息不对称与激励相容，就会像周县令头两个月那样，把噪声当贪污，把精确当正义，设计出没人能执行的规则；懂了它，才知道好制度往往不是“量得更准”，而是“让说真话比说假话划算”。

#### 叁｜商业故事

#### 故事

2021年春天，成都玉林路一家菜市场里，卖卤味的王姐发现自己每天要倒掉半盆没卖完的鸭脖。隔壁摊卖凉菜的刘哥更惨，下午三点后基本靠“买一送一”清货。两人一合计，拉上市场里卖水果、卖馒头、卖冷吃兔的六个摊主，建了个微信群，名字叫“玉林晚八点”。

玩法很简单：每晚七点半，群主在群里发一张“盲盒菜单”——当天各家没卖完的尾货，随机组合成30元、50元两档，限自提，八点半截单。第一天只卖了七单，但没人在意——反正本来也要倒掉。

转折来自一个叫小周的姑娘。她是附近小区的租客，连续三天抢到30元档，晒了朋友圈：一袋卤鸭脖、两个馒头、一盒草莓、半斤凉拌木耳，配文“30块吃三顿”。这条朋友圈被转发到隔壁两个小区，群一下子从80人涨到400人。

王姐嗅到了变化。她不再只发尾货，开始主动“做盲盒”：卤味摊每天多备十份“边角料拼盘”（鸭翅尖、藕片、豆干混装），定价12元，专供盲盒。水果摊把卖相不好的“丑果”切盒，3盒10元。馒头摊干脆推出迷你杂粮包，6个5元。成本没变，但原本要扔的东西有了固定销路。

到2022年底，“玉林晚八点”已经覆盖周边五个小区，群主从摊主变成了小周——她辞了行政工作，专门做“社区尾货盲盒”运营，向每个摊主收每月200元“上架费”，外加每单5%的抽成。摊主们算过账：王姐的卤味摊每月多赚1800元，刘哥的凉菜损耗从每天40%降到12%。小周自己月入过万，还不用囤货、不用送货，只维护群和排班表。

2023年，有人模仿他们在城南开了“晚九点盲盒”，小周没慌——她把群名注册成了商标，还跟摊主签了独家协议：同一个市场只合作一家同类摊位。现在她正琢磨把模式打包成SOP，卖给其他社区想做副业的人，定价999元一套。

#### 商品 / 服务
社区尾货盲盒订阅群：整合菜市场摊主当日损耗品，以盲盒形式限时低价卖给周边居民，组织者赚上架费与抽成。

#### 商业模式拆解
- **客户**：两端——供给端是菜市场中小摊主（损耗高、无线上能力）；需求端是周边价格敏感型居民（租客、年轻家庭）。
- **价值**：摊主端解决“卖不完只能扔”的损耗痛点；居民端用低价获得非标准化但足量的食材，省去比价和挑选成本。
- **收入**：向摊主收月度上架费（200元/摊）+ 每单5%交易抽成；后期增加SOP售卖（999元/套）的培训收入。渠道靠微信群+朋友圈裂变。
- **成本或护城河**：核心成本是群运营人力（几乎为零库存）；护城河是“同一市场独家合作”的排他协议+群名商标，防止同区域复制。
- **个人启发**：副业不一定要自己生产商品——找到一群“有损耗品却不会卖”的小供给方，用轻量组织方式（群+盲盒规则）把他们的尾货标准化成可交易单元，你赚的是组织效率和信任溢价。
