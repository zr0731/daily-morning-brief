#### 壹｜游戏创意

#### 今日出圈观察
最近《小丑牌》（Balatro）和《背包乱斗》（Backpack Battles）这类“构筑+算分”游戏持续出圈，钩子很清晰：每局 10～20 分钟，玩家在有限槽位里做乘法式组合，结算瞬间数字爆炸带来强反馈。传播点在于“我这套牌/摆位能打出多少分”天然适合截图和短视频挑战。留存靠不断解锁新卡牌/角色改变构筑思路，付费点通常是一次性买断或皮肤/扩展包，不做重内购。对个人开发者友好之处是：核心系统是数值与 UI，不需要复杂 3D 和联机。

#### 创意 1｜《骰子工坊》
- 卖点：把骰子当卡牌来“锻造”，每局用 6 个骰面槽位打连锁算分。
- 核心循环：每回合从随机骰池选 3 颗骰子，拖到 6 格工坊槽里触发相邻加成（同色连击、点数递增、复制面），点“熔炼”结算得分并消耗一颗耐久；玩家每分钟在“选骰—摆位—看连锁预览—改一颗再结算”之间循环。
- 范围边界：不做 3D 骰子物理、不做多人对战、不做关卡地图；只做单局 Roguelike 式 10 波目标分，失败即重开。
- 原型可行性：核心是 ScriptableObject 定义骰面 + 2D 拖拽 UI + 结算公式，Cursor 能直接生成摆位校验和分数预览代码，2～3 周可出可玩循环。

#### 创意 2｜《夜班档案》
- 卖点：在一间深夜档案室里，靠比对文件细节找出“不该存在的那一页”。
- 核心循环：每份档案给 4～6 个字段（姓名、日期、编号、印章），玩家对照规则手册逐项核查，点选异常字段并提交；每分钟处理 2～3 份文件，错误会累积“怀疑值”，正确则解锁新规则条目。
- 核心循环补充：不做自由文本推理，只做“规则匹配+找不同”，降低叙事写作量。
- 范围边界：不做分支剧情树、不做配音、不做 3D 场景；固定一间办公室背景 + 文件 UI 面板，规则手册用数据表驱动。
- 原型可行性：本质是数据校验 + UI 状态机，Cursor 写规则表和异常生成器很快，2 周内可做 20 份手写档案的原型。

#### 创意 3｜《摊位大作战》
- 卖点：经营一个 3 平米夜市摊位，靠“备货—定价—应付突发”撑过 7 天。
- 核心循环：每天开局选 3 种食材和初始定价，营业时顾客按耐心条排队，玩家点击补货、调价、赶走闹事者；每分钟在“看队列—补货—微调价格—处理事件”之间切换，关门后结算利润并升级设备。
- 范围边界：不做自由建造、不做外卖系统、不做多摊位连锁；只做单摊位 + 固定事件池（城管、下雨、网红探店）。
- 原型可行性：时间片驱动的简单模拟 + 数值表 + 2D 摊位 UI，Cursor 能生成事件调度和顾客队列逻辑，3 周可出 7 天循环原型。

#### 创意 4｜《回声地牢》
- 卖点：你每走一步，地牢会“记住”并在地图另一端复制你的路径来堵你。
- 核心循环：回合制网格移动，玩家每走 3 步，系统在镜像位置生成一个“回声”沿相同路径移动；玩家每分钟在“规划路线—预判回声位置—用道具改向—拾取钥匙开门”之间循环。
- 范围边界：不做实时战斗、不做随机地牢生成器、不做多敌人 AI；只做固定 5 层手工关卡 + 一种回声机制 + 3 种道具。
- 原型可行性：网格回合制 + 路径记录回放是纯 C# 逻辑，Cursor 能快速写回声模拟和碰撞判定，2 周可出 5 层可通关原型。

#### 创意 5｜《投标风云》
- 卖点：异步对抗的“暗标拍卖”，你出价时看不到对手，只看到上一轮的历史报价。
- 核心循环：每局 8 轮，每轮系统展示一件资源（地皮/专利/人才），玩家秘密出价并分配“信誉点”；开标后最高价得资源但扣信誉，信誉最低者出局；每分钟在“读历史报价—估对手心理—分配出价与信誉—看开标结果”之间循环。
- 范围边界：不做实时联机、不做聊天系统、不做长线养成；只做异步回合制，对手可以是真人历史记录或简单 AI 出价模型。
- 原型可行性：核心是回合状态机 + 出价记录表 + 简单 AI 估值函数，Cursor 能生成异步对战的数据结构和开标逻辑，3 周可出单机对 AI 的可玩原型。

#### 贰｜概念寓言

#### 寓言

老周在城南开了三十年面馆，招牌是雪菜肉丝面。每天凌晨四点熬骨汤，六点开门，十点卖完收摊。街坊都说老周的面有股“定力”，吃下去一天不乱。

老周的儿子小周在城里做数据分析，去年回家过年，看见父亲账本上记着“今日售出碗数：127”，旁边还画了个笑脸。小周说：“爸，你这账本只有结果，没有过程。”老周说：“过程我心里有数。”小周摇头：“你心里有数的东西，写下来才能验证。”

于是他给父亲装了一套系统：一个摄像头数人头，一个扫码器记点单，一个厨房打印机计时。老周嘴上说“花里胡哨”，但也没拆。头一个月数据出来，小周发现一个怪事：每天上午八点四十到九点十分，出餐速度骤降，平均每碗面多等两分半。而这段时间客人最多，排队最长。

“爸，你九点前后是不是去上厕所？”小周问。老周瞪眼：“你才上厕所。我那时候在切第二锅雪菜。”小周调出录像：老周确实在切菜，但每切几下就要扭头看一眼门口，看见有人站着等，就放下刀去催厨房，回来又忘了切到哪儿，重新找位置。二十分钟里他切了四回“第一刀”。

“你被排队的人干扰了。”小周说，“你的注意力在‘催单’和‘切菜’之间来回切换，每次切换都重新加载一次状态。这叫——”他没说下去，因为他意识到父亲听不懂术语。

老周不服：“那我以前怎么没觉得慢？”小周说：“因为你以前只记总数。总量掩盖了波动。你不看见那个两分半，它就不存在。”

老周想了三天，做了个决定：把切雪菜挪到凌晨四点，和熬汤一起干完。九点那一锅改成提前备好的半成品，只下锅不切。小周说：“那新鲜度呢？”老周说：“雪菜腌了两天，凌晨切和九点切没区别。有区别的是我切的时候老抬头。”

改了之后，八点四十到九点十分的平均出餐时间降回一分钟以内。但小周又发现一个新问题：十点收摊前最后二十分钟，翻台率突然下降，客人吃完不走。老周说：“那是老张、老李几个老伙计，每天最后来，吃完聊天。”小周说：“那你催啊。”老周说：“催什么，他们是我最早那批客人。我年轻时摆摊，他们帮我搬过桌子。”

小周没再说话。他在报表上加了一行备注：“末段翻台率低——非流程问题，社交资本维护成本。”老周看见这行字，乐了：“你早这么说不就完了。”

年底小周回来，老周主动递给他一张纸，上面画了个流程草图：凌晨备料 → 六点开门 → 八点四十前完成所有切配 → 九点到十点纯出餐 → 十点后不赶人。旁边写了一行字：“别让换刀的人抬头看门。”

小周问：“你这叫什么方法？”老周说：“叫‘别把脑子切碎了用’。”小周想了想，说：“我们课上管这个叫——算了，你叫得比我准。”

那天晚上老周喝了二两酒，跟儿子说：“你那个摄像头啊，最值钱的地方不是数人头。是让我看见我自己的手在哪儿停的。”小周说：“爸，你这句话比我导师说得透。”

#### 揭晓：概念名

**认知负荷理论中的“任务切换成本”与“外部认知负荷”**——准确地说，本寓言核心对应的是**认知负荷理论（Cognitive Load Theory）** 中“**外部认知负荷**”与“**任务切换代价**”的耦合：当工作记忆被无关信息（如排队人数、催单压力）占用时，用于核心任务（切菜、出餐）的认知资源被挤占，表现为效率下降；而将高切换需求的任务（切菜+监控排队）拆解为低切换需求的序列（凌晨切完+九点纯出餐），本质是**降低外在认知负荷、优化任务编排**。老周最后那句“别让换刀的人抬头看门”，就是一句民间版的操作定义。

#### 隐喻对照

| 故事元素 | 对应含义 |
|---|---|
| 老周只记“售出碗数” | 只关注输出总量，忽略过程波动与瓶颈 |
| 摄像头+扫码器+计时器 | 引入过程数据采集，使隐性成本可见 |
| 八点四十到九点十分出餐变慢 | 任务切换成本：切菜与监控排队之间反复切换，工作记忆反复“重新加载” |
| 老周每切几下抬头看门口 | 外部认知负荷：无关刺激（排队人数）占用有限认知资源 |
| 把切雪菜挪到凌晨 | 任务序列优化：将高切换需求任务拆分为低切换需求阶段，降低外在负荷 |
| 十点后不赶老张老李 | 并非所有“低效”都该优化——社交资本维护是另一种目标函数 |
| “别让换刀的人抬头看门” | 操作层面的认知负荷管理原则：减少任务边界处的注意力泄漏 |

#### 为何值得懂

研究生阶段的大量工作——实验设计、编码、写作、读文献——本质上都是**在有限工作记忆下编排高切换成本的任务**。不懂认知负荷，就会把“我很忙”误当成“我在推进”，把总量数据当成过程真相；懂了它，才知道该在哪儿砍掉“抬头看门”的动作，以及哪些“低效”其实不该砍。

#### 叁｜商业故事

#### 故事

2023年春天，成都玉林菜市场卖卤菜的陈姐发现，隔壁摊位的王哥每天下午四点准时收摊，比她还早。一问才知道，王哥把下午没卖完的卤鸭脖、藕片分装成小袋，挂到小区团购群里，标价“次日达盲盒，9.9元一袋，随机荤素搭配”。群里三百多号人，每天下午五点开抢，十分钟清空。

陈姐跟着试了一周。她发现盲盒不能随便装——素菜多了没人要，得保证每袋至少两样荤的，成本压不住。于是她调整策略：上午正常卖，下午两点把预估卖不完的货单独分出来，按“荤素7:3”配比装袋，每袋成本约6元，卖9.9元。微信群一开团，附近三个小区的住户直接接龙，第二天早上到摊位自提。三个月后，她建了第二个群，专门做“卤味下午茶拼单”——满30元打九折，凑够20单免配送费请隔壁水果摊小刘骑车送。2024年夏天，陈姐的微信群贡献了摊位总流水的三成，剩货损耗从每天七八十块降到二十块以内。

#### 商品 / 服务
菜市场卤味摊的“剩货盲盒+社群团购自提”模式。

#### 商业模式拆解
- **客户**：菜市场周边三公里内、对价格敏感但追求“薅羊毛”体验的小区居民，尤其是下班晚、不愿进菜场细挑的年轻租客。
- **价值**：把“损耗”变成“惊喜”。对摊主，解决临期卤味卖不掉只能扔的痛点；对顾客，用9.9元买到原价15元左右的随机卤味，便宜且有趣，自提又省了配送成本。
- **收入**：盲盒差价（成本6元售9.9元，毛利率约39%）+ 拼单满减带来的增量客单价（满30元九折，实际拉动正价商品销售）。渠道完全依赖微信群接龙，零平台抽成。
- **成本或护城河**：核心成本是“分装人工+群维护时间”，护城河是“社区熟人信任+自提点物理距离近”——大平台复制不了菜市场摊主和住户之间的脸熟关系。
- **个人启发**：副业不一定要造新东西。先找自己手里“每天必然产生、但价值被低估的剩余物”（时间、库存、技能余量），用轻量社群做“限时低价+随机惊喜+自提/低成本交付”，把损耗变成现金流。关键是配比要控成本，别让“惊喜”变成“清仓甩卖”。
