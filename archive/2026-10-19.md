#### 壹｜游戏创意

#### 今日出圈观察
最近《小丑牌》（Balatro）和《背包乱斗》（Backpack Battles）这类“构筑+算分”游戏持续出圈，钩子是“每局都能凑出一个让自己意外的乘区组合”，传播点在于玩家会主动截图分享“这局伤害数字离谱”。留存靠的是短局制（10～20 分钟）加解锁新卡/新角色，付费点则很轻——买断或低价 DLC 即可，不逼氪。另一条线是《R.E.P.O.》带动的“物理协作+语音尖叫”派对向，传播靠主播切片，但个人开发者难做联机同步，暂不碰。

#### 创意 1｜骰子炼金铺
- 卖点：把骰子当原料扔进锅里“煮”出药水，每局凑出离谱的连锁反应。
- 核心循环：玩家每分钟在“选 3 颗骰子→放进 3×3 坩埚格→触发相邻骰子的元素反应→结算药水品质与金币→用金币买新骰面或扩格”。一局 12 轮，每轮 40 秒左右决策。
- 范围边界：不做实时战斗、不做剧情、不做联机；只做单机回合制、20 种骰面、8 种元素反应、3 个难度。
- 原型可行性：核心是二维网格上的相邻判定加乘区结算，Cursor 能直接生成 ScriptableObject 数据表和结算函数，2 周可跑通“扔骰子→算分→买骰面”闭环。

#### 创意 2｜夜班电梯
- 卖点：你是深夜写字楼的电梯员，靠“按楼层顺序”解谜，送对乘客、躲开不该开门的那层。
- 核心循环：玩家每分钟在“看乘客纸条→规划电梯停靠顺序→在电梯里和乘客对话获取线索→决定某层开或不开→结算乘客情绪与楼层异变”。一局 15 分钟，3 条支线结局。
- 范围边界：不做 3D 自由移动、不做战斗；只做 2D 电梯剖面图、点击式楼层选择、对话树、10 个乘客事件。
- 原型可行性：本质是状态机加对话树，Unity 的 UI 和 Timeline 足够，Cursor 写对话解析和楼层状态切换很快，3 周能出可玩垂直切片。

#### 创意 3｜废土快递：单程票
- 卖点：每局只送一单快递，路线自己画，油量、路障、劫匪全在纸上算。
- 核心循环：玩家每分钟在“看地图→用有限油量画路线→遭遇随机事件（修路/绕路/丢货）→抵达后按剩余油量和货物完整度结算报酬→用报酬解锁新车型/新路线”。单局 8～12 分钟，Roguelike 式路线生成。
- 范围边界：不做开放世界、不做实时驾驶；只做 2D 俯视地图、节点式路线、事件卡池、5 种车型。
- 原型可行性：路线绘制可用 LineRenderer 加节点吸附，事件用 ScriptableObject 卡池，Cursor 生成随机地图和事件结算逻辑，2～3 周可玩。

#### 创意 4｜小摊经济学
- 卖点：在夜市摆一个 2 平米小摊，靠“定价+备货+看人下菜”活过 30 天。
- 核心循环：玩家每分钟在“早上选进货品类与数量→下午定单价→晚上看客流类型（学生/情侣/加班族）→实时微调价格与吆喝→结算利润与口碑”。每天 3 分钟，30 天一个存档。
- 范围边界：不做 3D 摊位装修、不做联机交易；只做 2D 摊位界面、6 种商品、4 类客群、简化的供需曲线。
- 原型可行性：核心是数值模拟加 UI 滑块，Cursor 能快速生成供需公式和客群行为表，2 周可跑通“进货→定价→结算”循环。

#### 创意 5｜异步决斗棋
- 卖点：每天花 5 分钟布一步棋，对手隔天用 AI 或真人回一步，像下棋版“部落冲突”。
- 核心循环：玩家每分钟在“看对手上一步→在 5×5 棋盘上放一个单位或改一条规则→提交给服务器→看回放预测”。异步对局，单次操作 3～5 分钟，一天可开 3 局。
- 范围边界：不做实时联机、不做复杂兵种；只做 5×5 棋盘、6 种单位、异步回放、简单匹配（可先用 AI 对手）。
- 原型可行性：回合状态用 JSON 存服务器（可用 Firebase 或 Unity Gaming Services），Cursor 生成序列化与回放逻辑，3 周可出“布阵→提交→看 AI 回放”原型。

#### 贰｜概念寓言

#### 寓言

老周在城南开了三十年茶馆，最烦一种客人：坐下来先问“你们这茶怎么个好法”。他说，茶好不好，喝的人自己不知道么？

可偏偏有个姓林的年轻人，每周三都来，每次都点最便宜的高碎，然后掏出本子记东西。老周起初以为他是记者，后来发现他记的是“今天茶馆来了几拨人”“靠窗那桌坐了多久”“第二泡的茶汤颜色比我上次来时深了多少”。

“你记这些干什么？”老周终于忍不住问。

小林说他在做一项调查，研究为什么有的茶馆能开十年，有的半年就倒。他跑了四十多家，每家都蹲点记数据。老周笑了：“这还用研究？茶好、人勤快、房租别太贵，不就得了。”

小林摇头，说了件怪事。他最早统计了二十家茶馆，发现一个规律：**凡是门口摆绿植的，存活率高出三成**。他兴冲冲写进报告，导师看了一眼说：“你再去数数，摆绿植的茶馆是不是本来店面就大？”他一查，果然——大店面更爱摆绿植，而大店面本来就更扛得住亏。绿植和存活，其实都是“店面大”带出来的。

老周听得入神，给小林续了杯茶。小林接着说，他后来学乖了，专门找了一批“店面差不多大、位置差不多偏、老板年纪也差不多”的茶馆，硬是凑出两两配对的来比。有一对特别有意思：街东和街西各一家，装修几乎一样，连茶叶进货渠道都同一个。唯一差别是——街东那家老板每天开门前会把桌椅搬到门口，街西那家从不搬。

“那肯定是搬桌椅的生意好呗？”老周说。

“头三个月确实是这样。”小林翻着本子，“但半年后反过来了。街西那家开始有回头客，街东那家还是靠路过的人。我去问，街西老板说他从不搬桌椅，是因为他每天开门前那半小时在跟熟客打电话——问人家上次喝的什么、这次要不要留位子。桌椅搬出去招的是生客，电话打出去留的是熟客。”

老周沉默了一会儿，问：“所以你是想说，搬桌椅没用？”

“不是没用。”小林合上本子，“是**搬桌椅这件事，和‘老板愿不愿意花心思琢磨客人’绑在一起了**。愿意搬桌椅的老板，往往也愿意干别的；而那些别的，才是真正让茶馆活下来的原因。可你要是只看‘搬不搬桌椅’，就会以为是桌椅的功劳。”

老周给他倒了杯新茶：“那你现在怎么判断？”

小林指了指窗外：“我不看桌椅。我看老板记不记得住熟客喝什么。这个没法装，也没法靠‘摆绿植’‘搬桌椅’蹭出来。”

后来老周自己试了试：他把门口绿植撤了，桌椅也不搬了，但每天开门前给五个老客发消息问要不要留位。三个月后，流水没跌。

#### 揭晓：概念名

**遗漏变量偏误（Omitted Variable Bias）**：在估计某个变量 X 对结果 Y 的影响时，如果存在一个同时影响 X 和 Y 的未观测变量 Z 未被纳入模型，则对 X 效应的估计会有偏。通俗说：你以为是 A 导致了 B，其实是有个 C 同时导致了 A 和 B，而你漏掉了 C。

#### 隐喻对照

| 故事元素 | 对应含义 |
|---|---|
| “摆绿植的茶馆存活率高” | 观察到的 X–Y 相关（绿植 → 存活） |
| “大店面” | 遗漏变量 Z：同时影响是否摆绿植和是否存活 |
| 小林导师让他“再数数店面大小” | 识别混淆因素、检验替代解释 |
| 两两配对找“店面、位置、老板年纪都差不多”的茶馆 | 控制变量 / 匹配设计，阻断 Z 的干扰 |
| “搬桌椅”与“打电话留熟客”绑在一起 | X 与真实因果机制共同出现，造成表面相关 |
| 街东 vs. 街西的对照 | 准实验比较：在 Z 受控后看 X 是否仍有独立效应 |
| 老周撤绿植、不搬桌椅，改发消息留熟客，流水没跌 | 干预验证：去掉表面 X 后，真正的机制仍起作用 |

#### 为何值得懂

研究生做实证研究时，最常见、也最致命的错误就是把相关当因果，而遗漏变量偏误正是这种错误的数学形态——它不会让结果“看起来错”，只会让结果“看起来对”。懂得找 Z、控制 Z、或者至少说清楚“我漏了什么”，是从“会跑回归”到“会做研究”的分水岭。

#### 叁｜商业故事

#### 故事

2023年春天，成都玉林菜市场卖卤味的张姐发现，老顾客刘阿姨最近总在摊前叹气。一问才知道，刘阿姨独居，女儿在国外，自己做饭嫌麻烦，点外卖又觉得贵且不健康。“我就想吃口热乎的、软烂的，像你卤的肘子那种。”

张姐动了心思。她算了一笔账：自己每天下午四点出摊，上午正好空着。如果给附近几栋老居民楼的老人做“软烂套餐”——一荤一素一汤，少盐少油，用卤水底味，每份15元，两荤两素20元，提前一天微信接龙，第二天上午十点半送到小区门卫室。她拉了个“玉林邻里午饭群”，先拉了二十个熟客，让她们拉邻居进来。

第一个月只接了八单，亏了燃气费。但刘阿姨在群里发了条语音：“张姐的肘子比我女儿炖得还烂。”这句话像广告。第二个月三十单，第三个月七十单，张姐一个人忙不过来，把下岗的妹妹叫来帮忙。她没租店面，家里厨房改造一下，添了两口大锅，成本不到三千块。

到了夏天，张姐发现新需求：年轻人也进群了。有个做直播的小姑娘说，她下午开播前想吃口热饭，但外卖送太早凉了。张姐顺势加了“下午场”，三点半送一批，专供附近写字楼和直播间的年轻人，菜单换成“低卡卤味拼盘”——鸡胸、藕片、海带结，配糙米饭，22元一份。同一口卤锅，两套菜单，上午服务老人，下午服务年轻人。

2024年，张姐没扩规模，而是把“接龙+定时送”的模式教给了隔壁卖凉菜的王哥，抽他每单2元。王哥的群也满了。张姐现在每天只接四十单，利润稳定在每月六千左右，比她过去摆摊多一倍，且下午三点就收工。

#### 商品 / 服务
社区“定时卤味套餐”：以微信群接龙预售、固定时段集中配送的居家简餐服务。

#### 商业模式拆解
- **客户**：老旧小区独居老人（核心刚需）＋附近年轻上班族/主播（增量需求），两群人在同一地理半径内、不同时段消费同一供应链。
- **价值**：老人要“软烂、便宜、有人管”；年轻人要“热乎、低卡、不用等”。张姐用“预售接龙”消灭了外卖最大的痛点——配送时间不确定导致的口味衰减。
- **收入**：按份定价，老人餐15–20元，轻食拼盘22元；零门店租金；后期通过“模式授权+每单抽成”获得第二层收入。
- **成本或护城河**：改造成本极低，护城河是“熟人社群信任+固定配送时段养成的习惯”——邻居刘阿姨的一句语音比任何广告都值钱，后来者很难复制这群人的接龙习惯。
- **个人启发**：副业不必另起炉灶。先找到一个已经在你生活半径里、你本来就在做的“手艺”（卤味），然后问三个问题：谁在附近、什么时段、他们最烦什么（饭凉/太硬/太贵）。用微信群把“不确定的生意”变成“确定排期”，同一口锅就能吃两拨人。
